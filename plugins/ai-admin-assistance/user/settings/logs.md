If you are experiencing issues, the [WordPress AI Admin Assistance Plugin](https://www.wpaiplugins.dev/wordpress-ai-admin-assistance/) comes with debug logging functionality. To enable this, go to **Settings > Advanced** and enable the **Debug Logging** option.

The log is stored in your WordPress uploads folder. The full path is:

```
wp-content/uploads/ait-aiaa-logs/ait-aiaa.log
```

If ever you need to contact support with an issue, make sure to enable the debug logging first. It may give you your answer before even needing to reach out, or, at the very least, you can provide us with the log right away, so we can help you to address the issue more quickly.
