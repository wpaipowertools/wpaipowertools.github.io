title: Benefits of the Pro Version
---
The pro version of the [WordPress AI Admin Assistance Plugin](https://www.wpaiplugins.dev/wordpress-ai-admin-assistance/) includes several advanced features, such as inline guidance, workflows, acknowledgements, styling options and more!

Pro features include:

- **Inline Guidance**: Create guidance items that display inline, either instead of or in addition to in the panel.
- **Workflows**: Create step-by-step full guidance tutorials that show in the panel.
- **Acknowledgements**: Configure acknowledgements that can be shown to users, including critical ones that block access until accepted.
- **Styling Options**: Update the look and styling of several different elements in the help panel.
- **Import and Export**: Easily export settings and/or guidance and/or workflows, so you can import them into another site, speeding up your ability to create guidance on all the sites you develop.
- **Stay up to date**: Immediate access to all security and bug fix updates as well as to all new features that get added.
- **Priority support**: Priority support for pro users, with quick and effective help from a real person.
