Several options are available to you for customizing the guidance experience. To access them, in your WordPress admin, go to **Admin Guidance > Settings > Designer Guidance**. There you will find the following options:

- **Disable Designer Guidance:** This lets you disable the **Guidance** tab from the the admin assistance panel.
- **Max Guidance Items:** Set the maximum number of guidance items to show for a screen.
- **Warning Style:** Controls how "warning" guidance items will be styled.
- **Quick Help Links:** Create an optional list of quick links that will display at the bottom of the panel.

## Pro

With the [pro](../pro) version of our [WordPress AI Admin Assistance Plugin](https://www.wpaiplugins.dev/wordpress-ai-admin-assistance/), you have access to more guidance configuration options. These are:

- **Guidance Mode:** This lets you enable the use of inline guidance items, which are available only in the pro version.
- **Require Acknowledgements:** If this is enabled, acknowledgements can be shown to users, and critical acknowledgements can block access to wp-admin until accepted.
- **Acknowledgement Behavior:** Lets you decide whether acknowledgements should be per guidance item or only for critical items.
