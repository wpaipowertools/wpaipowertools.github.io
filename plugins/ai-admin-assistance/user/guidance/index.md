One of the main features of the plugin is the ability to create guidance items that show in the **Guidance** tab in the panel. This is an extremely powerful tool for developers to add help items to specific areas of the admin, so the for whom they created the site can get the help they need and not need further support or to have to contact you.

Here we'll cover the different aspects of setting up and using the admin guidance feature.
