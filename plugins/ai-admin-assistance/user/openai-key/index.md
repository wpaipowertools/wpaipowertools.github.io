The AI Admin Assistance plugin uses OpenAI to power its AI assistant feature. As such, if you would like to use this feature, you'll need to insert your OpenAI API key in the plugin settings. In this section, we cover how to create an OpenAI account, generate an API key and insert that key in our plugin.
