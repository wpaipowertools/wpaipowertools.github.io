This documentation will help you use AI Admin Assistance, a WordPress plugin that lets you create a help panel in WordPress, to display admin guidance, information, tutorials and plugin-specific guidance on any or ever admin screen. It also features an AI admin assistant that uses OpenAI to automatically retrieve help information for the current screen.

For help learning how to install the plugin, add your details and display them on your website, visit the [User Guide](user).
